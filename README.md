# Design and Evaluation of a Deep Learning-Based NLP Model for Context-Aware Text Classification

## Project Overview
This project uses Natural Language Processing and deep learning to classify movie reviews as positive or negative using the IMDB movie review dataset.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy and Pandas
- Scikit-learn
- Bidirectional LSTM (Bi-LSTM)

## Project Workflow
1. Dataset loading and inspection
2. Text preprocessing and tokenization
3. Sequence padding and label encoding
4. Bi-LSTM model building and training
5. Model evaluation
6. Sentiment prediction on new text

## Dataset
The project uses the IMDB dataset containing 50,000 movie reviews, with 25,000 positive and 25,000 negative reviews.

## Result
Test accuracy: 78.27%

## How to Run
1. Install the required Python libraries.
2. Place the IMDB dataset file in the project folder.
3. Run `nlp_deep_learning_model.py` using Python.
